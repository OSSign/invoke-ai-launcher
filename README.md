# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [Invoke-AI/launcher](https://github.com/Invoke-AI/launcher/) project.

## Where are the signed binaries published?
The signed drivers are published by the author on [Invoke-AI/launcher](https://github.com/Invoke-AI/launcher) and in the releases to the right.

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/invoke-ai-launcher/actions).
